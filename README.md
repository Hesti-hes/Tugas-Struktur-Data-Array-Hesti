# Description
program (Java dan Python) menggunakan struktur data array (fixed-size array) dengan kapasitas 10, untuk menyimpan sejumlah data mahasiswa (nim dan nama).

# Program memiliki menu sebagai berikut:
1.    Insert at beginning
2.    Insert at given position
3.    Insert at end
4.    Delete from beginning
5.    Delete given position
6.    Delete from end
7.    Delete first occurence
8.    Show data
9.    Exit
